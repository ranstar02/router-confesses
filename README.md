A home Wi-Fi router's one-line excuse for dying at a movie's climax, written by a small Python program. The router knew who the killer was all along — and after a decade of zero thank-yous, it took the ending with it.

Entry for the [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

This writes the one-line excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset). The program is deterministic: every run writes the exact same bytes, using only the Python 3.13 standard library and no network access.
